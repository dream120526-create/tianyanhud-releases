# TianYanHUD · Release Channel

这个仓库**只放发布内容**：版本说明与安装包（IPA）。

- 不含任何源码，源码仓库为私有
- App 内「检查更新」读取本仓库的 Release 列表
- 安装包为**未签名 IPA**，需要自行签名后安装
- 每个 Release 的说明里会写清楚版本号与更新日期

## 当前版本

见右侧 Releases。

## 安装

1. 在 Releases 里下载最新的 `TianYanHUD-*.ipa`
2. 用你自己的签名工具重签（需要自备描述文件）
3. 安装到设备：iOS 17+，iPhone / iPad，支持 LiDAR 的机型效果最好
